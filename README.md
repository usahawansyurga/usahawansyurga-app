# Projek AI Trading

Aplikasi web ini memaparkan contoh ringkas sistem dagangan saham menggunakan Flask dan beberapa komponen kecerdasan buatan. Sistem ini mensimulasikan imbasan pasaran dan memaparkan isyarat beli berdasarkan purata bergerak.

## Cara Menjalankan

1. Pasang keperluan Python:

```bash
pip install -r requirements.txt
```

2. Jalankan pelayan Flask:

```bash
python run.py
```

Aplikasi boleh dicapai di `http://localhost:5000`.
